# 🌍 CULTISO - Plateforme d'Intelligence Agrobusiness

**Mission :** Propulser la souveraineté alimentaire africaine en offrant des outils digitaux de pointe aux acteurs de l'agrobusiness.

## 🚀 Le Projet Actuel : MVP (Module Cultiplan)
Cultiso est un écosystème composé de 6 modules (Cultiplan, Cultisia, Cultiseil, Cultishop, Cultistock, Cultigreen). 
Le présent dépôt (MVP - V1) se concentre **exclusivement sur Cultiplan** : un outil de simulation financière et de création de business plans agricoles sous forme de Progressive Web App (PWA).

## 🛠️ Pile Technique (Stack)
* **Frontend :** Next.js (App Router) & TypeScript
* **Design System :** Ant Design (Mobile-First)
* **Backend & Auth :** Supabase (PostgreSQL)
* **Déploiement :** Vercel
* **Infrastructure :** Terraform
